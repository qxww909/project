Group 8 - Smart Checkout & Backend Management System
📖 项目简介 (Project Overview)
本项目是一个基于 Python 开发的电商结账与后台管理控制台系统。项目采用模块化设计，不仅实现了基础的折扣计算，还集成了用户身份验证、多支付方式路由、满额包邮规则，以及完整的账号与订单数据存储管理功能。系统支持持续的交互式操作，高度还原了真实电商后台的业务逻辑。

✨ 核心功能 (Core Features)
1. 智能计算模块 (calculate_final_total)
多身份折扣：支持学生（9折）、儿童（8折）、老人（85折）及成人（原价）的自动打折逻辑。

优惠券与运费：支持优惠券抵扣；订单折后满 99 元包邮，不满 99 元自动收取 10 元运费。

极值保护：当优惠券金额过大时，系统会自动将金额归零，防止出现负数账单。

2. 安全与支付模块 (verify_user_identity & process_payment)
身份验证：结账前自动拦截空账号或未登录用户，保障系统安全。

支付路由：内置支付白名单机制（支持支付宝、微信、信用卡、PayPal），自动拦截不支持的非法支付方式（如比特币）。

3. 数据管理模块 (Data Management)
账号管理：使用字典模拟数据库，支持注册新账号、查看所有账号、删除指定账号。

订单管理：使用列表模拟数据库，支付成功后自动生成订单存档，支持查看历史订单与删除（撤销）订单。

4. 交互式主控台 (run_interactive_system)
通过 while True 循环提供直观的 CLI（命令行）菜单。用户无需重启程序，即可反复进行注册、结账、查单、删单等操作，模拟真实的后台管理体验。

💡 技术亮点 (Technical Highlights)
高内聚低耦合：核心计算、支付路由、数据存储逻辑完全拆分，符合现代软件工程规范。

健壮性防错：使用 try-except 捕获用户输入异常（如输入非数字金额），防止程序崩溃。

财务精度保障：所有金额结算均使用 round(amount, 2) 保留两位小数，防止浮点数精度丢失。
